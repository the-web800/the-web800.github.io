House800以外に、noteでも記事を投稿しています（[リンク](https://note.com/web800)）。

noteの方が通知も受け取りやすいですし、ユーザーも多いので、普通の記事はnoteの方に投稿する予定です。

でもnoteにはこんな問題があります。

- コードブロックのハイライトが充実していない
- インラインのコードブロックが使えない
- 自由度の高い埋め込みなど、独自の機能が使えない

コーディングを扱うブログでは困りますよね。

こちらではこのように、`inline` コードブロックも、通常のコードブロックのハイライトも使えます。

```cpp
int main() {
    std::cout << "Hello, World!" << std::endl;
}
```

なので、こちらでは主に独自の機能を必要とするもの等を投稿しようと思います。
他にも、作品紹介やリリースノートなど、いろいろ出せたらいいなと思っています。
