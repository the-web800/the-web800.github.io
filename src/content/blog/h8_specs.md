House800の技術について簡単に紹介します。

## 使用技術

主にこんなものを使っています。
- Astro: この家の基礎。
- Svelte（一部）: エレベーターなど、状態管理が欲しいものに。
- Tailwind CSS: デザインの資材。
- Tailwind CSS Typography（prose）: ブログ等のデザイン。このページの本文も。
- Lucide: アイコン。いつか自作に変わるかも？
- lychee: リンク切れ検査員。
- Biome: この家の検査員。
- pnpm: パッケージ管理ツール。
- GitHub (GitHub Pages): 保管庫 兼 地主。

## 開発環境

いつも、MacBook Air (M2) とVSCodeを使っています。

## ブログ

ブログは、AstroのContent collectionsを使って、マークダウンで管理しています。

外部のCMSを使っても良かったのですが、なんか悔しいのでGit方式を採用しています。
